## PackManager

PackManager is a command line tool that can create, view and list pack and epack files. A pack file (both encrypted and unencrypted) is a simple archive format that allows for random access. One can view all the contents of a file without first extracting it. This includes seeking or jumping backwards some minutes within a large video file for instance. This can be useful for creating collections or playlists of things and transferring them. A single pack file might represent an album, an anime series, all your holiday photos, etc. You can append to the files, but the files are otherwise read-only.</p>
